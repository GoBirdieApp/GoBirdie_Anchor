# Security Policy

## Supported Versions

This repository contains the public evaluation version of GoBirdie Anchor.
Security fixes are applied to the active `main` branch.

## Reporting a Vulnerability

Please report security concerns privately by email:

- contact@GoBirdieApp.com
- GoBirdieApp@gmail.com

Include a concise description, reproduction steps if available, affected files or APIs, and any relevant environment details.

Please do not open public GitHub issues for suspected vulnerabilities.

## Scope

Reports are especially helpful when they involve:

- Exposed secrets, credentials, or private configurations
- Unsafe dependency behavior
- Incorrect handling of untrusted inputs
- Issues that could affect downstream GoBirdie services or users

This project currently has no runtime npm dependencies.
