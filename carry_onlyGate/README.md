# Carry-only gate

Production estimation path when a player supplies **carry distances only** (plus onboarding).

Given a target carry, this gate tries to solve ball speed, launch angle, and spin inside club-specific bands;
mainly shaped by LPGA to PGA anchors and handicap. Then it derives apex and landing angle from the shared ball-flight model.
Output profiles are tagged
